## 4. Блокеры с доказательствами

### 4.1. Платные вызовы не имеют единого барьера

`CLAUDE.md §1` требует, чтобы каждый платный вызов проходил через одну функцию-чекпойнт
`is_paid_video_allowed()`. **Такой функции в коде нет.**

Фактическая защита — одно условие в конвейере:

```python
# worker/pipeline.py:92
if cfg.video_mode == "provider":
    ...  # generate_clip — платный
```

Оно закрывает только премиум-видео. Два других платных вызова выполняются **всегда**:

```python
# worker/pipeline.py:67   ElevenLabs — платно за символы
cost = tts_step.synthesize(cfg, scene["narration"], audio_path)

# worker/pipeline.py:85   fal.ai Flux — платно за изображение
cost = image_step.generate_image(cfg, scene["image_prompt"], image_path)
```

**Следствие:** прогон в «безопасном» режиме тратит деньги на озвучку и кадры. Название
режима вводит в заблуждение.

### 4.2. `MVP_SAFE_MODE` не существует в коде — `DOC_DRIFT`

```
grep -rn "MVP_SAFE_MODE" --include=*.py --include=*.ts --include=*.tsx .
→ НЕ НАЙДЕН НИГДЕ В КОДЕ

grep -rln "MVP_SAFE_MODE" docs/ CLAUDE.md
→ CLAUDE.md, docs/BIBLE.md, docs/STATUS.md, docs/RISKS.md
```

Четыре документа предписывают флаг, которого нет. В коде вместо него два других:
`SCRIPT_MODE=llm|mock` и `VIDEO_MODE=kenburns|provider` (`worker/config.py:32,52`).

По `CLAUDE.md §0` расхождение кода и документа **не приводится в порядок молча**.
Решение — за основателем, варианты в §6.

### 4.3. Два вызова без таймаута

```python
# worker/steps/image_step.py:26
result = fal_client.subscribe(cfg.fal_image_model, arguments={...})

# worker/steps/video_step.py:31
result = fal_client.subscribe(cfg.fal_video_model, arguments={...})
```

`fal_client.subscribe` ждёт завершения задачи на стороне провайдера **без ограничения**.
Остальная сеть закрыта корректно: `httpx.Client(timeout=120)`, `subprocess ... timeout=900`.

**Следствие:** зависшая задача fal останавливает воркер целиком. `requeue_stale_jobs`
вернёт задачу в очередь через 30 минут, но сам процесс останется занятым — и подберёт
её снова. Это ровно тот сценарий, из-за которого в BIBLE появился раздел про Runway.

### 4.4. Финальный MP4 не проверяется

```python
# worker/pipeline.py:130
final_duration = media.media_duration_sec(final_path)
...
db.insert_render(project_id, final_url, final_duration)
```

Измеряется только длительность. Критерии приёмки из `CLAUDE.md §8` — наличие видео- и
аудиопотока, совпадение разрешения с пресетом, отличие последнего кадра от кадра за две
секунды до конца, яркость и пиковый уровень звука выше порога — **не проверяются**.

Чёрное видео нужной длины с тишиной пройдёт текущую проверку и будет показано как готовое.

### 4.5. Нет учётных данных

Проект Supabase не создан, миграции `supabase/migrations/0001_init.sql` и `0002_aspect_ratio.sql`
не применены, ключи Anthropic / ElevenLabs / fal.ai отсутствуют. Сквозной прогон невозможен
физически, независимо от состояния кода.

## 5. Что в порядке и переписывать не нужно

Проверено чтением; заново не изобретать:

- **Очередь на Postgres** — `claim_next_job()` через `FOR UPDATE SKIP LOCKED`, возврат
  зависших задач, `project_id uuid not null unique` в `jobs` против дублей.
- **Лимиты пользователя** — `MAX_CONCURRENT_PER_USER`, `MAX_DAILY_PER_USER`
  (`studio/app/api/projects/route.ts:36-70`), ответ `429` вместо тихого запуска.
- **Возобновление по сценам** — `if scene.get("audio_url"): continue`; сбой на 4-й сцене
  не оплачивает заново первые три.
- **Учёт затрат** — `db.log_cost()` на каждом платном вызове, цены собраны в `config.COSTS`.
- **Порядок стадий** — озвучка раньше визуала, длина сцены равна реальной длине голоса.
- **Ядро рендера** — форматы, переходы, субтитры; проверено настоящим файлом 06.09.2026.

## 6. Два решения, которые принимает основатель

`CLAUDE.md §9` — агент этого сам не решает.

### Решение A. Как соединить сайт и продукт

| Вариант | Суть | Плюс | Минус |
|---|---|---|---|
| **A1 (рекомендую)** | перенести маршруты `studio/` внутрь `web/`: лендинг на `/`, продукт на `/app` | один домен, один деплой, форма из обложки ведёт в реальную генерацию | правки в 8-10 файлах, нужна склейка middleware языков и сессии Supabase |
| A2 | развернуть `studio/` отдельным проектом, ссылка с сайта | быстрее всего | два домена, два дизайна, разрыв в пути пользователя |
| A3 | переключить Vercel на `studio/` | лендинг и продукт в одном приложении сразу | теряется текущий лендинг с тремя языками |

### Решение B. Что делать с `MVP_SAFE_MODE`

| Вариант | Суть |
|---|---|
| **B1 (рекомендую)** | ввести `MVP_SAFE_MODE` как единственный внешний выключатель денег: при `1` отключает **все** платные вызовы — озвучку, кадры и видео; `SCRIPT_MODE`/`VIDEO_MODE` остаются внутренними |
| B2 | признать документы устаревшими и переписать их под `SCRIPT_MODE`/`VIDEO_MODE` |

B1 ближе к `CLAUDE.md §1` и закрывает блокер 4.1 заодно.

### Что это меняет для P0

Половина цепочки P0 — от постановки задачи до валидного MP4 — теперь
`VERIFIED`, а не «написано и выглядит правильно». Проверка не требует ни
ключей, ни денег и повторяется одной командой.

Осталась вторая половина: браузер должен доходить до этого конвейера.
Это решение A (слить сайт и приложение), принятое основателем 07.09.2026.
