## Качество и продвинутый движок

- **Character Bible** — неизменяемые атрибуты персонажа + референсное изображение + проверка
  идентичности зрительной моделью с перегенерацией при дрейфе
- **World / Visual Bible** — архитектура, палитра, логика света, реквизит, эпоха, язык камеры
- **Director 2.0** — не один текст, а production bible: сюжет, персонажи, мир, локации, стиль,
  шот-лист, план камеры, план света, план звука, правила непрерывности
- **Director Critic** — цикл «черновик → критик → правка» только для дорогих режимов
- **Smart Planner 2.0** — оценка всех сцен по движению, важности, риску непрерывности и ценности
  премиума, затем выбор лучших, а не первых подходящих
- **Provider Router** — динамический выбор провайдера по качеству, цене, задержке и доступности
- **Автоматический QA** — технические проверки + смысловые через зрительную модель + точечная
  перегенерация только сбойного ассета
- **Оценки качества** — соответствие промпту, визуальное качество, консистентность персонажа,
  качество движения, звук, синхронизация субтитров
- **Монтаж по битам музыки**
- **Локальный движок движения** — наезд, отъезд, панорама, вертикальное раскрытие, параллакс,
  2.5D-камера, лёгкая тряска, имитация перефокусировки
- **Длинная форма** — иерархия «фильм → эпизод → сцена», сводки непрерывности, бюджет на эпизод
- **Параллельная генерация** — сцены пачкой, голос параллельно визуалу, с учётом лимитов частоты

## Долгосрочная картина

Автономная продакшн-система: понимает задачу → пишет историю → создаёт библии персонажей и мира →
планирует биты, сцены и кадры → распределяет бюджет → выбирает провайдеров → генерирует
референсы и ассеты → озвучивает → подбирает музыку и звуковой дизайн → монтирует под ритм →
проверяет качество → чинит плохие сцены → рендерит во все форматы.

**Тезис, ради которого это может стать компанией:** базовые модели обесценивают отдельные
возможности генерации, и ценность смещается вверх — в рабочий процесс, оркестрацию, монтаж,
непрерывность, контроль стоимости и надёжность. Но этот тезис доказывается платящими клиентами,
а не длиной этого файла.
