# Аудит Horsteppe от 16.11.2026 и что по нему сделано

Ответ на ТЗ основателя «Complete engineering audit, architecture redesign & production
optimization» + «Customer accounts, packages, payments & video credits». Продукт не менялся:
автономное производство видео по промпту. Новое — только то, что ТЗ требует прямо (кабинет,
пакеты, оплата, кредиты).

**Как проверялось.** Код прочитан по активному пути (сайт `web/`, сборщик `worker/`, миграции
`supabase/`). Цены и возможности моделей — по документации провайдеров (источники в конце).
**Ни одного платного вызова не сделано** (CLAUDE.md §1): всё, что зависит от живого ответа
провайдера, помечено `IMPLEMENTED_UNTESTED` в [STATUS.md](STATUS.md).

## 1. Fable 5.2 — что это на самом деле

| Вопрос | Ответ |
|---|---|
| Что это | Языковая модель Anthropic, id `claude-fable-5-2`. **Не видеомодель**: видео, картинки и звук она не делает |
| Где у нас полезна | «Режиссёр»: сценарий, раскадровка, оценка сложности каждого кадра (от неё зависит, какая видеомодель возьмёт кадр) и разбор фото товара для рекламы |
| Цена | $8 за млн входных токенов, $40 за млн выходных. Opus 5.5 — $4 / $20, Sonnet 5.5 — $2 / $10, Haiku 5.5 — $0,10 / $0,50 |
| Ограничения API | Размышление включено всегда и входит в `max_tokens`; `temperature`, `budget_tokens` и принудительный `tool_choice` дают ошибку 400; глубина — `output_config.effort`; организация Anthropic должна хранить данные 30 дней (иначе 400) |
| Отказы фильтра | Бывают ложные. Подключён серверный запасной путь (`fallbacks`, бета `server-side-fallback-2026-07-01`): отвечает соседняя модель, платим по её тарифу |
| Стоимость сценария | ≈ $0,10–0,25 на ролик при `effort=medium` (допущение до первых счетов). Это ~10% себестоимости ролика 15 с |
| Лучше ли она везде | Нет. Для сценария — сильнейшая; для дешёвых массовых задач (подписи, классификация) избыточна |

**Сделано:** режиссёр переведён на Fable 5.2 (`LLM_MODEL`, по умолчанию), потолок ответа 16 000
вместо 4 000 (раньше ответ с размышлением мог оборваться, а вызов был бы оплачен), запасная модель
при отказе, цена считается по модели, которая реально ответила, режиссёр рекламы видит до двух
фото товара. Таймаут 600 с (штатный SDK; короче — SDK повторяет и платим за обрыв дважды).
Откатиться: `LLM_MODEL=claude-opus-5-5` в `worker/.env`.

## 5. Пакеты, оплата, кредиты (дополнительное требование ТЗ)

Путь: **пакет → заказ → оплата → кредиты → идея → ролик → результат.**

| Требование ТЗ | Как сделано | Где |
|---|---|---|
| Пакеты из КП, без выдуманных цен | 15 пакетов из КП 09.11 в таблице `packages`, **выключены**; включение и цена — в кассе | миграция 0007, `/ru/admin` |
| Анализ экономики до внедрения | себестоимость по уровням кодом сборщика | [MONEY.md §10](MONEY.md) |
| Кабинет | кредиты по уровням, пакеты, заказы с инструкцией оплаты, история движений | `/[lang]/account` |
| Оплата провайдером региона, кредиты только после подтверждения | сейчас ручное подтверждение основателем; функция `grant_order_credits` сверяет сумму и идемпотентна — онлайн-провайдер подключается к ней | `/api/admin`, миграция 0007 |
| 1 кредит = 1 успешная генерация | резерв при заказе ролика, списание при «Готово», возврат при ошибке и при ролике с оговоркой | триггер на `projects.status` |
| Нет двойного списания, нет минуса | атомарный `update … where available > 0`, `check (available >= 0)`, резерв на проект один | миграция 0007 |
| История | `credit_ledger`: покупка, резерв, списание, возврат | кабинет |
| Подключить к движку без перестройки | сборщик о кредитах не знает; уровень пакета = потолок моделей | `pipeline.capped_importance` |

**Почему онлайн-провайдер не подключён.** Stripe в Казахстане недоступен; Robokassa.kz,
Freedom Pay, банковский эквайринг и Kaspi требуют ИП/ТОО и договора, а ключей и правовой формы у
меня нет. Писать интеграцию вслепую, без документации конкретного договора и без возможности
проверить, — значит выдумывать API (запрещено ТЗ). Ручной путь работает уже сейчас; точка
подключения провайдера готова.

## 8. Решения основателя

1. Применить `supabase/migrations/0007_credits.sql` в Supabase → SQL Editor.
2. Vercel → Environment Variables: `ADMIN_EMAILS` (ваша почта), `PAYMENT_DETAILS` (реквизиты
   для перевода; без них покупатель увидит «напишите на почту с номером заказа»).
3. Какие пакеты и по каким ценам продавать: включить в `/ru/admin` (см. [MONEY.md §10](MONEY.md)).
4. Онлайн-оплата: правовая форма (ИП/ТОО) и провайдер (Robokassa.kz / Freedom Pay / банк / Kaspi).
5. Режиссёр: оставить Fable 5.2 или перейти на Opus 5.5 (вдвое дешевле сценарий). Для Fable —
   включить хранение данных 30 дней в организации Anthropic.
6. Эконом на Kling 2.5 Turbo (как в КП, втрое дешевле Wan 3.0) или оставить Wan 3.0.
7. Где жить сборщику 24/7 вместо Mac.
8. Перезапустить сборщик, чтобы он взял новый код.
