## Шаг 1. Supabase

1. Открыть проект на supabase.com (или создать новый).
2. В SQL Editor выполнить по порядку:
   - `supabase/migrations/0001_init.sql`
   - `supabase/migrations/0002_aspect_ratio.sql`
3. Создать приватный bucket `projects` в Storage.
4. Из Settings → API забрать три значения: `URL`, `anon key`, `service_role key`.

> `service_role` — ключ с полным доступом. Он живёт только в воркере и в
> серверной части приложения, и **никогда** не попадает в браузер.

## Шаг 2. Ключи провайдеров

| Сервис | Зачем | Где взять |
|---|---|---|
| Anthropic | сценарий и разбивка на сцены | console.anthropic.com |
| ElevenLabs | озвучка | elevenlabs.io → **платный план**, на бесплатном нет коммерческих прав |
| fal.ai | кадры | fal.ai — сначала проверить, что аккаунт не заблокирован |

Если fal.ai недоступен — скажите, переведу генерацию кадров на другого
провайдера: это один файл, `worker/steps/image_step.py`.

## Шаг 3. Файлы настроек

Скопировать шаблоны и вписать значения:

```bash
cp worker/.env.example worker/.env
cp studio/.env.example studio/.env.local
```

**Ключи не нужно никуда присылать.** Достаточно вписать их в эти два файла —
они в `.gitignore` и в репозиторий не попадут.

Для первого запуска в `worker/.env` оставить безопасные значения:

```env
SCRIPT_MODE=mock      # без обращения к Anthropic, бесплатно
VIDEO_MODE=kenburns   # без платной видеогенерации
VIDEO_FORMAT=9:16
TRANSITION_SEC=0.5
SUBTITLES=1
```

В таком режиме весь конвейер проходит целиком и стоит примерно ноль —
платит только ElevenLabs за озвучку.

## Шаг 4. Локальная проверка

```bash
cd worker
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Параллельно:

```bash
cd studio && npm install && npm run dev
```

Открыть http://localhost:3000, зарегистрироваться, создать проект.
**Критерий готовности:** в браузере появился проигрываемый MP4.

## Шаг 5. Публикация

**Приложение** — Vercel, корневая папка `studio/`, переменные из `.env.local`.

**Воркер** — Railway, Render, Fly.io или обычный VPS. В репозитории лежит
`worker/Dockerfile`, в него уже включён шрифт с кириллицей для субтитров.

```bash
docker build -t horsteppe-worker ./worker
docker run --env-file worker/.env horsteppe-worker
```

> Воркер нельзя разместить на Vercel: там серверные функции ограничены по
> времени, а рендер идёт минутами. Нужен сервис, где процесс живёт постоянно.

## Порядок включения платных вещей

Не всё сразу. По одному, с проверкой счёта после каждого шага:

1. `SCRIPT_MODE=llm` — включить настоящий сценарий (Anthropic).
2. Прогнать 10 роликов, посмотреть на `cost_events` в базе.
3. Только потом `VIDEO_MODE=provider` — премиум-видео, самая дорогая строка.

Почему именно так — в [MONEY.md](MONEY.md): себестоимость ролика почти
целиком определяется премиум-секундами, и включать их вслепую нельзя.
