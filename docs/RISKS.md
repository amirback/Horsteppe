## Деньги

| Триггер | Что делаем |
|---|---|
| Счёт от провайдера вырос за неделю больше чем на $X | остановить платные вызовы через `MVP_SAFE_MODE=1`, открыть учёт затрат, найти проект-виновник |
| Провайдер поднял цену | пересчитать таблицу в [MONEY.md](MONEY.md), переключить режим Smart на дешёвого провайдера |
| «User is locked» или блокировка аккаунта у провайдера | переключиться на запасного, не пополнять сгоряча; выяснить причину блокировки до пополнения |
| Доля принятых с первого раза упала ниже 50% | остановить приём тестеров, две недели в промпты и пресеты; при 65%→40% себестоимость растёт на 59% |
| Тестер сгенерировал 20 роликов за час | включить ограничение частоты и бюджет на аккаунт в долларах |

## Технические

| Триггер | Что делаем |
|---|---|
| Прогон завис дольше 15 минут | найти вызов без таймаута; в Wave 1 премиум-путь выключен, значит проблема в LLM или изображениях |
| Ролик получился, но чёрный или без звука | `ffprobe` это не ловит — добавить проверки яркости и уровня звука из [BIBLE.md §6](BIBLE.md#6-definition-of-done--проверяемая-версия) |
| Субтитры исчезли после деплоя на сервер | шрифт с кириллицей отсутствует в контейнере — добавить шрифт в образ, это известная поломка при переезде с Windows |
| Финальный ролик короче суммы сцен | это нормальная математика наложения переходов, а не баг: 5×12 с с четырьмя переходами по 0.5 с = 58 с |
| Длительность не совпадает с запрошенной | источник истины — длительность голоса; расхождение в пределах ±20% багом не является |
| Премиум-клип короче сцены | не зацикливать (`-stream_loop`) — заметно как глюк; замораживать последний кадр (`tpad=stop_mode=clone`) — читается как приём |
| Падение на монтаже | не перегенерировать всё: готовые клипы лежат на диске, нужен кэш артефактов по хешу промпта |
| Двойной клик создал две задачи | серверная дедупликация по хешу промпта и настроек; блокировка кнопки — вторая линия обороны |

## Продукт

| Триггер | Что делаем |
|---|---|
| Из 10 роликов вы бы выложили ≤ 3 | **стоп продуктовой разработке**, две недели в качество: промпты, сценарий, пресеты движения |
| Тестер бросил ожидание на середине | показать первый кадр за ≤ 60 секунд и сделать ожидание неблокирующим |
| Тестер сделал одну попытку и ушёл | проблема в первом результате, а не в интерфейсе; смотреть запись экрана |
| Просят контроль над сценами | не строить редактор таймлайна — начать с перегенерации одной сцены |
| 20 интервью не дали ни одной предоплаты | менять beachhead, а не доделывать движок |

## Юридические

| Триггер | Что делаем |
|---|---|
| Клиент спрашивает про права на ролик | ответ уже написан в [PROVIDERS_LEGAL.md §3](PROVIDERS_LEGAL.md#3-права-на-результат--что-можно-и-что-нельзя-обещать-клиенту); «полные авторские права» не обещать |
| Content ID заявка на музыку у клиента | музыка должна была быть выключена; включать только из `music_library.json` с проверенной лицензией |
| Пользователь генерирует лица публичных людей или NSFW | блок-лист на входе; иначе бан аккаунта у провайдера остановит продукт целиком |
| Демо перед аудиторией с бесплатным ElevenLabs | перевести на платный план **до** демо: на бесплатном коммерческих прав нет |
| Архив проекта уходит ментору или в заявку | проверить, что в нём нет `.env`; при сомнении — ротировать ключи |

## Организационные

| Триггер | Что делаем |
|---|---|
| Появилось желание начать заново | их уже две кодовые базы; см. [BIBLE.md §2](BIBLE.md#2-развилка-кодовых-баз--решение-1) |
| Агент предлагает большой рефакторинг | лимит правки — 3 файла и ~150 строк; всё остальное разбивается |
| Хочется добавить фичу из бэклога | [BACKLOG_PARKED.md](BACKLOG_PARKED.md) не открывается до Gate B |
| Демо-день, а генерация занимает 8 минут | 3–5 роликов сгенерировать заранее; живая генерация на сцене — риск без выигрыша |
