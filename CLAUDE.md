# CLAUDE.md — контракт для AI-агента

**Проект:** Horsteppe — AI-режиссёр и монтажёр видео.
**Цель Wave 1:** один промпт → один играбельный MP4 → через веб-интерфейс.

Полная спецификация — [docs/BIBLE.md](docs/BIBLE.md). **Читать по разделам под конкретную
задачу, не целиком.**

---

## 0. Главное правило

> **Код — истина о том, ЧТО ЕСТЬ. Документ — истина о том, ЧТО ВАЖНО.**
> При расхождении: пометить `DOC_DRIFT`, **остановиться**, спросить человека.
> Никогда не приводить код к документу и документ к коду молча.

Это правило существует по конкретной причине: Bible объявлял веб-API и фронтенд как «в планах»,
а на диске уже лежала их реализация. Агент, честно следующий документу, построил бы третью
реализацию и удвоил проект.

---

## 1. Деньги

- `MVP_SAFE_MODE=1` — **значение по умолчанию**, а не опция. Платный путь включается только
  явным `MVP_SAFE_MODE=0` с разрешения человека.
- Ни одного платного вызова (Runway, ElevenLabs, fal.ai, OpenRouter) без явного «да» в чате
  и **оценки стоимости до запуска**.
- Полный конвейер агент **не запускает**. Предлагает команду — запускает человек.
- Каждый новый платный вызов в коде обязан проходить через одну функцию-чекпойнт
  `is_paid_video_allowed()`.

**Почему это важнее, чем кажется.** Правило «не делать платных вызовов» конфликтует с правилом
«проверяй результат, а не полагайся на вид кода». Конфликт разрешается в сторону трат, если не
поставить машинный барьер.

**Рекомендация основателю (требует вашего решения, агент это сам не делает):** добавить в
`.claude/settings.json` запрет на запуск движка и сетевых команд, и завести в тестах фикстуру,
которая роняет любой тест, дёрнувший сеть. Это превращает вежливую просьбу в физическое
ограничение.

## 2. Секреты

- Не читать и не печатать значения из `.env` — только проверка существования (`KEY=True/False`).
- Не паковать `.env` в архивы. Перед созданием zip — исключать, проверять `.gitignore`.
- При малейшем сомнении в утечке — **ротировать ключ**, а не рассуждать.

---

## 3. Границы правок

| Ограничение | Значение |
|---|---|
| Максимум файлов на задачу | **3** |
| Максимум изменённых строк | **~150** |
| При превышении | **СТОП** и предложение разбить задачу — не «доделаю заодно» |

**Активный путь** (список файлов — [BIBLE.md §4](docs/BIBLE.md#4-активный-путь)) — правки только
здесь. Любой файл вне списка — только с явным разрешением в чате.

**Три санкционированных сквозных изменения**, которые НЕ считаются запрещённым рефакторингом:
безопасный режим, изоляция проектов по `project_id`, учёт затрат. Без этой оговорки запрет
«не рефакторить» блокирует собственные задачи Wave 1.

Всё, чего нет в активном пути, считается замороженным legacy: не чинить, не улучшать, **не
удалять** — даже если выглядит мёртвым. Сначала доказать, что файл никто не импортирует.

## 4. Git

- Работа только в ветке `wave1/<название-задачи>`.
- Файлы добавляются **поимённо**.
- Запрещено: `git add -A`, `commit -a`, `reset --hard`, `checkout .`, `clean -fd`,
  любой `push --force`.
- `.gitignore`, `requirements*.txt`, версия Python и сборка FFmpeg — не трогать без разрешения.
- Новые зависимости не ставить.

## 5. Среда

Рабочая машина основателя — **Windows + PowerShell**. Команды с `&&` там не работают.
Python запускать с `PYTHONUTF8=1` — кодировка `cp1251` уже один раз ломала конвейер.

Прод — **Linux в контейнере**. Всё, что проверено только на Windows, на Linux считается
непроверенным. Первым отваливается вшивание субтитров: нужен шрифт с кириллицей в образе.

## 6. Каждая задача заканчивается артефактом

«Аудит», «реализовать безопасный режим», «заморозить движок» — это направления, а не задачи.
У задачи должен быть **выходной файл, который можно открыть**, и критерий остановки.

| Задача | Артефакт |
|---|---|
| Аудит активного пути | `docs/AUDIT.md`: файл → размер → дата → кто импортирует; отдельно список файлов ВНЕ активного пути |
| Безопасный режим | `tests/test_safe_mode.py`: при `MVP_SAFE_MODE=1` и заблокированной сети — ноль исходящих вызовов, все сцены `AI_VIDEO` понижены до `IMAGE_MOTION`, исходные решения сохранены в метаданных |
| Таймауты | тест на моках, проверяющий поведение при зависшем соединении |
| Сквозной прогон | путь к MP4 + вывод `ffprobe` + лог без обращений к платным провайдерам |

Отчёт в чате артефактом не считается: он теряется в следующей сессии.

## 7. Статусы

Единственное место хранения — [docs/STATUS.md](docs/STATUS.md).

`VERIFIED` ставится **только** при наличии вывода команды, полученного в текущей сессии.
«Прочитал код, выглядит правильно» — это `IMPLEMENTED_UNTESTED`, без исключений.

Метки: `VERIFIED` · `IMPLEMENTED_UNTESTED` · `PLACEHOLDER` · `PLANNED` · `BLOCKED` ·
`REGRESSED` · `DOC_DRIFT`.

---

## 8. Критерии приёмки сквозного прогона

Зафиксировано заранее, чтобы агент не ушёл чинить то, что не сломано:

- **Источник истины по длительности — голос.** Запрошенные секунды это цель с допуском ±20%.
  Расхождение внутри допуска **не является багом** и не чинится.
- Финальный MP4: >0 видеопотоков, >0 аудиопотоков, разрешение равно целевому пресету, код
  возврата 0.
- Последний кадр не совпадает с кадром за 2 секунды до конца.
- Средняя яркость выборки кадров выше порога; пиковый уровень звука выше порога.

Всё, что вне этих порогов, агент **фиксирует меткой, но не чинит** в рамках текущей задачи.

## 9. Что агент не решает сам

- Какую кодовую базу развивать.
- Тратить ли деньги у провайдера.
- Удалять ли legacy-модуль.
- Менять ли архитектуру.
- Что обещать клиенту про права на результат.

Это решения основателя. Агент готовит данные для решения и ждёт.
