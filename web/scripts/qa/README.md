# Стенд проверки сайта

Проверки в Chrome через протокол отладки — без puppeteer и без новых
зависимостей, только встроенный в Node WebSocket. Каждый скрипт печатает
✓/✗ по пунктам; именно их выводы стоят в `docs/STATUS.md`.

Нужны: Google Chrome по стандартному пути macOS и сайт, поднятый локально
(`npx next build && npx next start -p 3456`) или адрес в `BASE`.

| Скрипт | Что доказывает |
|---|---|
| `layout.mjs [папка]` | нет горизонтальной прокрутки и ошибок консоли на 6 ширинах (360…2560); снимки экрана |
| `nojs.mjs [папка]` | что видно до загрузки JavaScript |
| `motion.mjs` | анимации останавливаются при «уменьшить движение» |
| `fps.mjs` | кадры в секунду при процессоре ×4 медленнее |
| `gen.mjs` | форма: превью фото, бюджет «1,5», черновик при уходе на вход. Нужны `p1.png` и `p2.png` рядом со скриптом |
| `e2e.mjs` | вход, шапка на статичной странице, API, меню, выход |
| `poll.mjs` | опрос: раз в 3 с, спит в фоне, стоп после 404 и ухода |

`e2e.mjs` и `poll.mjs` работают с настоящей базой: нужен одноразовый аккаунт
в `QA_EMAIL` и `QA_PASS`. Создайте его через `/api/auth/signup` и **удалите
после проверки** — проекты скрипты не создают, опрос работает на подменённом
ответе API.

Пример:

    BASE=https://horsteppe.vercel.app PAGES=/ru,/en node scripts/qa/layout.mjs /tmp/shots
