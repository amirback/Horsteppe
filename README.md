# Horsteppe

**AI-режиссёр и монтажёр видео.** Опишите ролик обычными словами — система напишет сценарий,
спланирует сцены, создаст визуал, озвучит, смонтирует и отдаст готовый MP4.

🌐 **Сайт:** https://horsteppe.vercel.app

## Ближайшие три действия

Взято из [BIBLE.md](docs/BIBLE.md). Порядок важен.

### 1. Закрыть развилку кодовых баз (полдня)

У проекта **две** кодовые базы одного продукта: движок `AI_Video_Studio_v3` и веб-приложение
`~/Desktop/ai video`. Вторая уже умеет то, что первая только планирует — очередь задач,
возобновление после сбоя, учёт затрат, лимиты, авторизацию и деплой.

Пока не решено, какая из них — база продукта, любая работа рискует быть сделанной дважды.
Четыре вопроса, на которые нужен ответ — в [BIBLE.md §2](docs/BIBLE.md#2-развилка-кодовых-баз--решение-1).

### 2. Пройти Gate 0 — проверить, что в движке реально есть (5 минут)

Откройте PowerShell в папке рабочей копии движка и выполните:

```powershell
Get-ChildItem -Recurse -Filter *.py | Select-String -Pattern 'subprocess|ffmpeg|imageio' | Measure-Object
```

Число в строке `Count` — это сколько мест в коде реально работают с видео.
**Если ноль — движка, который монтирует ролики, в этой копии нет**, и развилка из пункта 1
решается сама собой. Подробности — в [BIBLE.md §3](docs/BIBLE.md#3-где-мы-на-самом-деле-гейты-вместо-процентов).

### 3. Сделать безопасный режим первым изменением в коде

`MVP_SAFE_MODE` выключает все платные видеосервисы. Он должен появиться **до** починки таймаутов,
иначе вы платите Runway за то, чтобы научиться не зависать на Runway.

## Сайт

Лендинг на Next.js, полностью статический, деплоится на Vercel автоматически при каждом
изменении в ветке `main`.

```bash
cd web
npm install       # один раз
npm run dev       # локальный просмотр на http://localhost:3000
npm run build     # проверить, что собирается
```

Тексты сайта на двух языках лежат в одном файле — [web/app/lib/content.ts](web/app/lib/content.ts).
Чтобы поменять любую надпись, править нужно только его.

Заявки с сайта приходят письмом на почту основателя. Отдельная база для заявок не заводилась
намеренно: форма, которая молча теряет письма, хуже, чем её отсутствие.
