# Шрифт для субтитров

Положите сюда `.ttf` с поддержкой кириллицы — например `DejaVuSans.ttf`
(лицензия Bitstream Vera, свободная) или `NotoSans-Regular.ttf` (OFL).

**Зачем.** Субтитры вшиваются через libass. В облегчённых Docker-образах
системных шрифтов нет вообще, и вместо русского текста появятся пустые
квадраты — причём тихо, без ошибки. Файл рядом с воркером переживает
переезд в контейнер, системный шрифт — нет.

Порядок поиска: `SUBTITLE_FONT_FILE` → эта папка → системные пути.

Альтернатива для Docker: `RUN apt-get install -y fonts-dejavu-core`.
